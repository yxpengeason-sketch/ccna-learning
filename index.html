🎯 CCNA 200-301 考前實戰衝刺與考場指南

🚀

考前 48 小時黃金策略：不做全新題，聚焦三大核心

1. 重跑錯題本 Lab：針對 OSPF、VLAN Trunk、ACL、NAT 等配置盲點重敲指令，建立肌肉記憶。
2. 高頻翻卡快篩：快速過濾 50 張模組重點卡片，鎖定協定埠號、Timer 與 AD 值。
3. 考場證件確認：Pearson VUE 考場嚴格要求雙證件（主要證件：效期內護照或身分證；次要證件：健保卡/駕照/信用卡，需含英文姓名拼音或本人簽名）。

⏱️ 考場配速與不可回頭原則

CCNA 正式考試沒有「Previous」返回按鈕，一旦點擊 Next 提交即無法回頭修改：

  • 單選/多選題：控制在 ≤ 50~60 秒/題，直覺判斷。
  • 實機題（PBQ / Labs）：預留 6~8 分鐘/題。
  • 遇卡關題目勿糾結超過 2 分鐘，選取最合理答案後果斷推進。
🧪 PBQ 實機題標準答題 SOP

進入實機題畫面請嚴格遵循四步排查流程：

  • ① 摸底：先下 show running-config 與 show ip int brief 確認既有拓撲。
  • ② 防呆：確認介面已 no shutdown 且目標 VLAN 已建立（show vlan brief）。
  • ③ 配置：依題目指示精確鍵入目標指令。
  • ④ 雙向 Ping 驗證：端對端確認連通性。
💾 實機題最後一步：保存組態

部分題型未保存組態將無法被閱卷系統正確抓取狀態：

  • 每完成一台設備配置，務必在特權模式（#）執行：
    copy running-config startup-config
    。
  • 交卷前再次確認所有裝置皆已完成存檔。
🧐 多選題（Choose 2 / 3）避坑訣竅

依考古題統計多選題佔比高達 15%~20%，作答時善用排除法：

  • 動詞對應：注意題幹要求的是 Configure、Verify 還是 Describe。
  • 絕對詞陷阱：出現 Always、Never、Only 時提高警覺。
  • 協定層級：確認題幹問的是 L2（MAC/VLAN）、L3（IP/Routing）還是 L4（Port）。

📋 CCNA 200-301 官方 6 大領域自我驗收矩陣

考綱領域與官方權重 核心必備考點與秒殺觀念 關鍵驗證指令 (Verify CLI)
1. Network Fundamentals
權重 20% 		• IPv4 VLSM Block Size速算（含 /31 RFC 3021 點對點與 /32 主機）
• IPv6 縮寫規範（RFC 5952）、位址分類（Global 2000::/3、Link-Local fe80::/10）
• TCP 三向交握、常見協定 Port 埠號、單模 (SMF) vs 多模 (MMF) 光纖 		show version
show interfaces [status]
show ipv6 interface brief
2. Network Access
權重 20% 		• 802.1Q Trunk 封裝、Native VLAN 不打標與安全隔離
• Rapid PVST+ 根橋選舉（最低 Priority > 最低 MAC）、PortFast/BPDU Guard
• EtherChannel 模式匹配（LACP active/passive vs PAgP desirable/auto）
• WLC 與 AP 架構（Split-MAC、CAPWAP、WPA3-SAE Dragonfly 握手） 		show vlan brief
show interfaces trunk
show spanning-tree vlan X
show etherchannel summary
3. IP Connectivity
權重 25% (核心) 		• 路由仲裁黃金律：① 最長前綴匹配 (LPM) > ② AD 值 > ③ Metric
• 靜態路由（下一跳 IP vs 出介面）、浮動靜態路由備援設計
• Single-Area OSPFv2/v3 鄰居 7 大必要條件、DR/BDR 選舉（非搶佔性）、Cost 計算 		show ip route [prefix]
show ip ospf neighbor
show ip ospf interface brief
show standby brief
4. IP Services
權重 10% 		• NAT/PAT 轉換邏輯（overload 關鍵字、Inside Local vs Inside Global）
• DHCP DORA 四步驟、跨網段 ip helper-address（轉單播至 UDP 67）
• NTP Stratum 階層、Syslog 嚴重度等級（0 Emergency ~ 7 Debugging）、QoS CoS (L2) vs DSCP (L3) 		show ip nat translations
show ip dhcp binding
show ntp status
show logging
5. Security Fundamentals
權重 15% 		• Layer 2 防禦四件套：Port Security（Protect/Restrict/Shutdown）、DHCP Snooping、DAI、IPSG
• ACL 匹配規則（Top-Down 逐條比對、末端隱含 Deny Any、Standard 靠目的 vs Extended 靠來源）
• AAA 架構（TACACS+ TCP 49 全加密 vs RADIUS UDP 1812 密碼加密）、SSH 安全登入配置 		show port-security interface
show ip dhcp snooping binding
show ip arp inspection
show access-lists
6. Automation & Programmability
權重 10% 		• Controller-Based SDN 架構（Catalyst Center / DNA-C）、三平面職責（Control vs Data vs Management）
• 北向 API（REST/JSON）vs 南向 API（NETCONF XML/SSH 830, RESTCONF HTTPS 443）
• REST API CRUD 動詞映射與 HTTP 狀態碼（200 OK, 201 Created, 401 Unauthorized, 404 Not Found）
• 自動化組態工具定位（Ansible: Agentless/Push/YAML vs Terraform: IaC/HCL） 		curl / Postman API 呼叫
JSON / YAML 語法格式校驗
